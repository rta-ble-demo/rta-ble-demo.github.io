# RTA Bus Lane Enforcement — demonstration prototype

A clickable prototype of the Bus Lane Enforcement platform, published as a single
self-contained page: https://rta-ble-demo.github.io/

Illustrative data throughout — no live camera feeds and no backend integration.
The page carries `noindex`, so it is reachable by link but not by search.

This repository holds a generated build only. Source is maintained privately.
